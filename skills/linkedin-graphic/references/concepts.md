# Concepts: metaphors, layouts, headlines

## The ideation method (do this every time)
1. **Find the structure of the content** before thinking visually. What shape is it?
   - *sequence* (steps, a pipeline, a timeline) · *hierarchy* (org, tiers, a tree) ·
     *network* (a system of inputs, tools and outputs) · *distribution* (counts per
     category or country) · *roster* (a set of people or companies) · *comparison* (old vs
     new, before and after) · *cycle* (a loop or flywheel) · *filter* (many become few) ·
     *schedule* (things that run at times).
2. **List 8+ physical systems with that same shape** (use the library below, and go
   beyond it). Prefer systems that are also a **pun on the topic**: health → ECG, angels
   → halos, GTM "engine" → trains, pipeline → plumbing, content "machine" → wiring.
3. **Score each one** from 1 to 5 on: structural fit (does every part carry content?),
   topic pun, novelty (not used by this client, not one of the references), stop-power
   at thumbnail size, and buildability in SVG/HTML. Pick the best total.
4. **Write the mapping table.** If you cannot fill 4+ rows with real content, pick another
   metaphor.
5. **Pick the CTA keyword from the metaphor** for lead magnets (PULSE for ECG, TICKET for
   a boarding pass, BLUEPRINT, RECIPE, SIGNAL, ORBIT …).

## Metaphor library (by content shape)
These are starting points. Mix them, adapt them, invent new ones.

**Sequence / pipeline / playbook**
- Subway or metro map (lines = channels, stations = steps, interchanges = handoffs)
- Assembly line or conveyor with stations · Factory floor plan
- Plumbing or refinery (crude leads → refined meetings) · Water treatment stages
- Recipe card or kitchen line (mise en place → stations → the pass → plated deal)
- Flight path, or boarding pass + gates · Airport baggage system
- Board game path (Monopoly-style squares, with "go to jail" = common mistakes)
- Rocket launch sequence with T-minus countdown · Mission control timeline
- Relay race / F1 pit stop (each crew member = a tool or role)
- Domino chain · Rube Goldberg machine · Circuit board traces from input pins to output

**Hierarchy / tiers / team**
- Org chart with coloured departments · Sports formation (positions = roles)
- Building cross-section (floors = layers of the stack, elevator = automation)
- Iceberg (visible vs hidden work) · Pyramid / food chain
- Family tree / root system (roots = data sources, trunk = engine, fruit = results)
- Ship deck plan (captain, engine room, crew) · Military command / chess pieces

**Network / system / stack**
- Brain or neural wiring map · Constellation / star chart (bright stars = key tools)
- Power grid with substations · Telephone switchboard · Patch bay / modular synth
- City map (districts = categories, roads = data flow) · Airline route map
- Motherboard (CPU = AI, RAM = memory, ports = integrations)
- Periodic table of tools (element tiles with symbols, numbers and groups)
- Solar system (orbits by priority or frequency) · Galaxy of dots (volume) + named logos

**Distribution / counts / proof**
- ECG / seismograph spikes = values · Equaliser bars · Skyline (building height = value)
- Stock ticker / candlesticks · Thermometer / gauges / cockpit instruments
- Heat-map calendar (GitHub contribution grid) · Waffle of 100 squares (each = 1 person)
- Leaderboard / podium · Scoreboard (stadium, split-flap) · Receipt (line items, total)
- Nutrition label ("% daily value") · Weather map / radar · Tide chart

**Roster / list of people or companies**
- Ring or radial roster around a centre badge · Trading cards in a binder grid
- Yearbook page · Fantasy-draft board · Seating chart / round table
- Passport stamps · Museum wall labels · Wall of fame with plaques
- World map pins with flags · Spotify-Wrapped-style tiles

**Comparison**
- Split screen: old way (grey, chaotic wires) vs new way (clean, glowing)
- Two vending machines, two kitchens, two cockpits · Before/after blueprint
- Ladder vs elevator · Paper map vs GPS

**Cycle / flywheel**
- Clock face / 24h dial (what runs when) · Washing-machine cycle · Gear train
- Racetrack lap with sectors · Seasons wheel · Ferris wheel cabins

**Filter / funnel**
- Glass funnel / sieve stages · Gold panning · Coffee filter / espresso machine
- Airport security lanes · Sorting hat / mail sorting facility · Distillation column

## Layouts by post type

**Lead magnet (comment KEYWORD).** Hero ~60%, a stat row or proof cards (2–4), then a
**full-width CTA pill** (≥ 96px tall) with the keyword in an accent colour and a "what you
get" line. The graphic previews the resource and does not give everything away: show the
structure, tease the depth ("+40 more inside").

**Roster / list.** The geometry carries the list (ring, grid, map). Add a category legend in
mono caps with counts, and faces or logos on every item.

**System / stack.** A network or machine metaphor. Show tool logos in tiles, mono names for
skills and agents, counts after labels, a clear input → engine → output flow, and a footer
proof line.

**Playbook / process.** Numbered steps with `STEP 01 · NAME` mono eyebrows, one hero
object the steps run through, and an end state badge (CLOSED WON, LIVE, SHIPPED).

**Team / org.** A command node at the top, then category columns with colour-coded
headers, then rows with mono names and short descriptions. Show the totals in the sub.

**Proof / result.** One giant number (counter animation) plus the mechanism that produced
it, drawn small and dense underneath. Timeframe in the footer.

**Comparison.** Split the canvas. The losing side is desaturated and messy, the winning side
uses the accent and order. The same items appear on both sides so the change is legible.

**Market map / landscape.** Categories as regions, logos inside, and a "you are here" or
trend arrow. Date-stamp it in the eyebrow.

## Headline formulas (3–8 words, one emphasis)
- **[Famous brand]-Style [Thing].**: borrowed authority
- **Every [audience] Needs a [role/thing]**: universal claim
- **The [Topic] Machine / Engine / Stack / OS**: systemisation
- **Who [does X] at [famous list].**: curiosity about a list
- **[Year] [Topic] Playbook**: timeliness + utility
- **[Number] [niche] [things]**: a list with a specific count (the number in the accent colour)
- **How [company] [gets result] in [time]**: case study
- **[X] is dead. [Y] runs it now.**: contrarian (use rarely)
- **The [N]-[unit] [result] system**: e.g. "The 4-Hour Pipeline System"
- **I mapped every [thing] [audience] uses**: research effort as the hook

Sub line: one sentence of concrete numbers ("12 departments. 60 AI agents. One brief.")
or an italic serif line that adds human texture.

## Anti-patterns (reject these concepts)
- Generic icon grids with no metaphor ("5 tips" with clip-art icons)
- A metaphor that only decorates (a rocket in the corner of a bullet list)
- Stock 3D blobs, gradient meshes with no content, AI-art backgrounds
- Fewer than ~20 labelled items (looks empty next to the references) or walls of sentences
- The same metaphor this client used in the last 10 graphics
- Rebuilding a reference (a train-station GTM board, an angel ECG, an AI-team org chart in
  12 colours, a Forbes ring) with new words
