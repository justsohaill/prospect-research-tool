# Examples made with this skill

Test graphics produced by following SKILL.md end to end, from a topic to a concept brief,
then HTML, render, QA and fixes. They show the **level of finish** expected. Do not reuse their
metaphors for real client work without a real reason: each new graphic gets its own concept.

| Folder | Metaphor | Theme | Post type |
|---|---|---|---|
| `periodic-table-ai-outbound/` | Periodic table (tools = elements, stack = compound) | paper | Lead magnet (comment ELEMENTS) |
| `crm-blackout/` | City in a blackout (segments = buildings, AI agent = power station) | custom night | Proof / case study |

The author identities in these examples (Maya Torres / Outbound Lab, Rafael Vidal /
nightshift.ai) are **fictional demo identities**, and the CRM numbers are illustrative.
Each folder holds the HTML source, the 2x PNG still, the MP4 and the QA report.
